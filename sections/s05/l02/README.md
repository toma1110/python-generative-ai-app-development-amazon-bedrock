# Pythonのエラー表示を読み分ける

リポジトリのルートで`cd sections/s05/l02`を実行し、このフォルダーへ移動します。

まず`python syntax_error.py`を実行します。Pythonはプログラムを実行する前に止まり、`SyntaxError`、誤りのある行、位置を示す`^`を表示します。`if True`の末尾にコロンを加えて保存し、同じコマンドを再実行してください。「構文を修正しました」と表示されたら確認できています。練習後はコロンを取り除き、最初の状態へ戻してください。

次に`python runtime_error.py`を実行します。今度はプログラムが動き始めてから、存在しない`missing.txt`を読む箇所で`FileNotFoundError`になります。例外名、該当するソース行、呼び出し元へたどるtracebackの各行を確認します。パスを`present.txt`へ直して再実行すると「確認用ファイルを読みました」と表示されます。確認後はパスを`missing.txt`へ戻してください。

構文エラーは実行開始前に見つかり、実行時例外は処理中に発生します。どちらも原因を直した後に同じコマンドを再実行して確かめます。
