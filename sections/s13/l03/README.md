# ファイルを読み、JSONをPythonの値にする

リポジトリのルートで`cd sections/s13/l03`を実行します。`python main.py`を実行し、3件の名前と状態が表示されることを確認します。

`Path(__file__).with_name("cases.json")`は、このプログラムと同じフォルダーにあるファイルの場所を表します。`Path`はクラス、ここで作られる`path`はそのインスタンス、`read_text(encoding="utf-8")`はインスタンスのメソッド呼び出しです。戻り値は文字列です。`json.loads`は文字列を解析し、この例では辞書を要素に持つリストを返します。

`cases.json`で1件の`status`を`ok`から`needs_review`へ変更して保存し、同じコマンドを再実行します。該当する表示が変わることを確かめたら、変更した値を`ok`に戻してもう一度実行してください。

ファイルがない場合の案内を確かめるには、`cases.json`の名前を一時的に変えて`python main.py`を実行します。ファイルが見つからない旨が表示されます。最後にファイル名を`cases.json`へ戻し、再実行して通常表示を確認します。

`python -m unittest -v`では、読み取った値、存在しないファイル、JSON文法が不正な場合をそれぞれ確認します。
